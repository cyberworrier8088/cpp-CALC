# cpp-CALC
a Calculator Build for learning C++

Features:
- Support: Addition, Subtraction, multiplication, Divition
- Terminal Interface
- That have A website for download

## How to Run
two why to run:

### Method 1

linux:

```bash

git clone https://github.com/cyberworrier8088/cpp-CALC.git
cd cpp-CALC
chmod +x main
./main

```

windows:

```bash

git clone https://github.com/cyberworrier8088/cpp-CALC.git
cd cpp-CALC

g++ main.cpp -o main.exe

```
click and run

### Method 2 (linux only)

Use the build releases

step1: use my website: [site](https://cpp-calec.netlify.app/)

step2: click download 

step3: terminal open that file

step4: 
```bash

chmod +x main
```
